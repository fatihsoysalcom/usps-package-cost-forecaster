# USPS Package Cost Forecaster

This Python script simulates a tool to predict potential unexpected shipping surcharges from carriers like USPS. It prompts the user for both declared and actual package dimensions and weight. The script then applies simplified rules for dimensional weight, oversize packages, and weight discrepancies to identify and report potential additional costs before shipping, helping users avoid surprise charges.

## Language

`python`

## How to Run

Save the code as `usps_cost_predictor.py`. Open a terminal, navigate to the file's directory, and run `python usps_cost_predictor.py`. Follow the prompts to enter package details.
